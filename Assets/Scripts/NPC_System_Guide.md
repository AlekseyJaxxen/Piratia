# 🎯 Система NPC для Piratia 2.0

## 📋 **Описание**

Система NPC позволяет создавать интерактивных персонажей с контекстным меню, настраиваемыми диалогами и кнопками действий. NPC автоматически спавнятся через MonsterSpawner и поддерживают взаимодействие с игроками.

## 🔧 **Компоненты системы**

### **NpcBehaviour.cs**
- Основной компонент для NPC
- Настраиваемые параметры: имя, диалог, кнопки, радиус взаимодействия
- Автоматическое создание World Space Canvas для отображения имени
- Отслеживание близости игроков
- Интеграция с контекстным меню

### **NpcContextMenu.cs**
- UI система для отображения контекстного меню NPC
- Автоматическое создание кнопок на основе настроек NPC
- Позиционирование меню рядом с курсором
- Закрытие меню при отдалении игрока

### **MonsterSpawner.cs (обновлен)**
- Добавлена поддержка спавна NPC через `NpcSpawnConfig`
- Автоматическое создание контейнеров для NPC
- Поддержка респавна NPC
- Настройка свойств NPC через конфигурацию

### **PlayerMovement.cs (обновлен)**
- Обработка левого клика по NPC
- Автоматическое приближение к NPC при клике издалека
- Показ контекстного меню при близком взаимодействии

### **NpcSystemInitializer.cs**
- Автоматическая инициализация системы NPC
- Создание NpcContextMenu если его нет в сцене

## 🎮 **Как использовать**

### **1. Настройка NPC префаба**

1. Создайте GameObject с тегом "NPC"
2. Добавьте компонент `NpcBehaviour`
3. Настройте параметры:
   - **Npc Name**: Имя NPC
   - **Dialogue Text**: Текст диалога
   - **Interaction Radius**: Радиус взаимодействия (по умолчанию 3f)
   - **Name Tag Scale**: Масштаб Canvas для имени (по умолчанию 0.005f)
   - **Name Tag Font Size**: Размер шрифта имени (по умолчанию 1f)
   - **Button Texts**: Массив названий кнопок (например: "Bank", "Trade")

### **2. Настройка MonsterSpawner**

1. В компоненте `MonsterSpawner` найдите секцию "NPC Spawn Configs"
2. Добавьте новую конфигурацию NPC:
   - **NPC Prefab**: Префаб с NpcBehaviour
   - **Spawn Center**: Точка спавна
   - **Radius**: Радиус спавна
   - **Count**: Количество NPC
   - **Respawn**: Включить респавн
   - **Respawn Time**: Время респавна
   - **NPC Properties**: Имя, диалог, кнопки, радиус взаимодействия

### **3. Инициализация системы**

1. Добавьте `NpcSystemInitializer` на любой GameObject в сцене
2. Система автоматически создаст NpcContextMenu при старте

## 🎨 **Взаимодействие с NPC**

### **Флоу взаимодействия:**

1. **Левый клик по NPC**:
   - Если игрок далеко → автоматическое приближение
   - Если игрок близко → открытие контекстного меню

2. **Контекстное меню**:
   ```
   [NPC Name]
   [Dialogue Text]
   
   [Button 1] [Button 2] ...
   ```

3. **Закрытие меню**:
   - Клик по кнопке в меню
   - Клик вне меню
   - Отдаление игрока от NPC

## 🔧 **Настройка кнопок**

### **Доступные действия:**
- **"Bank"** → Вызывает `OnBankButton()`
- **"Trade"** → Вызывает `OnTradeButton()`

### **Добавление новых действий:**

1. В `NpcBehaviour.cs` добавьте новый метод:
```csharp
public void OnCustomButton()
{
    Debug.Log($"[NpcBehaviour] Custom button clicked for {npcName}");
    // Ваша логика здесь
}
```

2. В `NpcContextMenu.cs` обновите `OnButtonClicked()`:
```csharp
case "custom":
    currentNpc.OnCustomButton();
    break;
```

## 🎨 **Кастомизация UI**

### **World Space Canvas:**
- Автоматически создается для каждого NPC
- Отображает имя NPC над головой
- Поворачивается к камере
- Настраивается через `nameTagPrefab`

### **Context Menu:**
- Автоматически создается при первом использовании
- Настраивается через `contextButtonPrefab`
- Поддерживает кастомные стили

## 🐛 **Отладка**

### **Полезные логи:**
- `[NpcBehaviour]` - Логи NPC
- `[NpcContextMenu]` - Логи контекстного меню
- `[PlayerMovement]` - Логи взаимодействия
- `[MonsterSpawner]` - Логи спавна NPC

### **Частые проблемы:**

1. **NPC не спавнятся**:
   - Проверьте, что Spawn Center назначен
   - Убедитесь, что точка спавна на NavMesh
   - Проверьте логи MonsterSpawner

2. **Контекстное меню не появляется**:
   - Убедитесь, что NpcSystemInitializer в сцене
   - Проверьте, что игрок близко к NPC
   - Проверьте логи NpcContextMenu

3. **Имя не отображается**:
   - Проверьте, что Camera.main назначена
   - Убедитесь, что TextMeshPro установлен

## 📝 **Пример конфигурации**

```csharp
// В MonsterSpawner
NpcSpawnConfig bankNpc = new NpcSpawnConfig
{
    npcPrefab = bankNpcPrefab,
    spawnCenter = townCenter,
    radius = 5f,
    count = 1,
    respawn = false,
    npcName = "Banker",
    dialogueText = "Welcome to the bank! How can I help you?",
    buttonTexts = new string[] { "Bank", "Trade" },
    interactionRadius = 3f
};
```
