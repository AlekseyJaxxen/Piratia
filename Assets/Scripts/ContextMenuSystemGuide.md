# 🎯 Система контекстного меню для игроков

## 📋 **Описание**

Система контекстного меню позволяет игрокам взаимодействовать друг с другом через правый клик мыши. При клике на другого игрока появляется меню с различными действиями.

## 🔧 **Компоненты системы**

### **ContextMenuUI.cs**
- Основной компонент для управления контекстным меню
- Создает UI панель с вертикальными кнопками
- Автоматически позиционирует меню рядом с курсором
- Обрабатывает закрытие меню при кликах вне его

### **PlayerMovement.cs** (обновлен)
- Добавлена обработка правого клика мыши
- Определяет, попал ли клик по игроку
- Вызывает показ/скрытие контекстного меню

### **PlayerCore.cs** (обновлен)
- Создает ContextMenuUI для локального игрока
- Инициализирует систему при старте игрока

## 🎮 **Как использовать**

1. **Показать меню**: Правый клик по другому игроку
2. **Скрыть меню**: 
   - Левый клик в любом месте
   - Правый клик в любом месте
   - Клик по кнопке в меню

## 🎨 **Текущие действия (заглушки)**

- **Действие 1**: Заглушка для первого действия
- **Действие 2**: Заглушка для второго действия  
- **Действие 3**: Заглушка для третьего действия

## 🔧 **Настройка**

### **Стилизация кнопок**
В `ContextMenuUI.cs` можно настроить:
```csharp
[SerializeField] private Color buttonNormalColor = Color.white;
[SerializeField] private Color buttonHoverColor = Color.gray;
[SerializeField] private Color buttonPressedColor = Color.blue;
```

### **Добавление новых действий**
В методе `CreateContextButtons()` добавить:
```csharp
CreateButton("Новое действие", OnNewAction);
```

И создать соответствующий метод:
```csharp
private void OnNewAction()
{
    Debug.Log($"Новое действие для игрока: {targetPlayer?.playerName}");
    HideContextMenu();
}
```
