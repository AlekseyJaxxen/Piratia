# Система ускорения первого удара с защитой от abuse

## Обзор

Система добавляет ускорение первого удара в BasicAttackSkill с защитой от злоупотребления orb walking (быстрыми первыми атаками).

## Компоненты

### 1. BasicAttackSkill - новые параметры

```csharp
[Header("First Attack Speed Settings")]
public float firstAttackTime = 0.1f; // Время первой атаки (ускоренная)
public float baseAttackTime = 1.0f; // Базовое время атаки
public float antiOrbWalkingCooldown = 0.8f; // Защита от orb walking
```

### 2. AntiOrbWalkingSystem

Система защиты от злоупотребления orb walking, которая:
- Блокирует быстрые первые атаки, если игрок находится в цикле атаки
- Управляет временными интервалами между атаками
- Сбрасывается после каста других скиллов

### 3. PlayerActionSystem - модификации

- `CalculateBasicAttackCooldown()` теперь учитывает ускорение первого удара
- Автоматически завершает циклы атаки через AntiOrbWalkingSystem
- Сбрасывает систему после каста других скиллов

## Как это работает

### Первая атака
1. Игрок начинает атаку - система проверяет `CanStartFastFirstAttack()`
2. Если прошло достаточно времени с последней атаки, первая атака выполняется быстро (`firstAttackTime`)
3. Запускается цикл атаки через `StartAttackCycle()`

### Последующие атаки
1. В цикле атаки все последующие атаки используют `baseAttackTime`
2. Система блокирует быстрые первые атаки до завершения цикла

### Защита от abuse
1. `antiOrbWalkingCooldown` предотвращает слишком частые быстрые атаки
2. Система сбрасывается после каста других скиллов
3. Цикл атаки завершается при остановке атаки

## Настройка параметров

### firstAttackTime
- **Рекомендуемое значение**: 0.1f - 0.3f
- **Описание**: Множитель времени первой атаки
- **Влияние**: 0.1 = очень быстро, 1.0 = как обычная атака
- **Формула**: `(1.0 / attackSpeed) * firstAttackTime`

### baseAttackTime
- **Рекомендуемое значение**: 1.0f
- **Описание**: Множитель базового времени атаки
- **Влияние**: 1.0 = стандартное время, 0.5 = в 2 раза быстрее
- **Формула**: `(1.0 / attackSpeed) * baseAttackTime`

### antiOrbWalkingCooldownMultiplier
- **Рекомендуемое значение**: 1.0f
- **Описание**: Множитель для anti-orb walking cooldown
- **Влияние**: 1.0 = равен реальному времени атаки, 0.8 = на 20% меньше
- **Формула**: `realAttackTime * antiOrbWalkingCooldownMultiplier`

### fastAttackResetTime
- **Рекомендуемое значение**: 1.0f
- **Описание**: Время бездействия для ресета быстрой атаки
- **Влияние**: 1.0s = быстрая атака доступна после 1 секунды без атак
- **Формула**: `timeSinceLastAttack >= fastAttackResetTime`

## Примеры использования

### Быстрая первая атака
```csharp
// Настройка для быстрой первой атаки
firstAttackTime = 0.1f;
baseAttackTime = 1.0f;
antiOrbWalkingCooldownMultiplier = 1.0f; // Равен реальному времени атаки
fastAttackResetTime = 1.0f; // Ресет через 1 секунду бездействия
```

### Умеренная первая атака
```csharp
// Настройка для умеренной первой атаки
firstAttackTime = 0.2f;
baseAttackTime = 1.0f;
antiOrbWalkingCooldownMultiplier = 0.8f; // На 20% меньше реального времени
fastAttackResetTime = 1.5f; // Ресет через 1.5 секунды бездействия
```

## Отладка

Система выводит подробные логи:
- `[BasicAttackSkill]` - информация о блокировке быстрых атак
- `[PlayerActionSystem]` - информация о расчете кулдауна
- `[AntiOrbWalking]` - информация о состоянии системы

## Совместимость с системой скорости атаки

### ✅ Полная совместимость
Система полностью совместима с существующей системой скорости атаки:

- **Формула времени атаки**: `(1.0 / attackSpeed) * multiplier`
- **attackSpeed** берется из `CharacterStats.attackSpeed`
- **multiplier** - это `firstAttackTime` или `baseAttackTime`

### 📊 Примеры расчетов

**Персонаж с attackSpeed = 1.0:**
- Первая атака: `(1.0 / 1.0) * 0.1 = 0.1s`
- Обычная атака: `(1.0 / 1.0) * 1.0 = 1.0s`

**Персонаж с attackSpeed = 2.0:**
- Первая атака: `(1.0 / 2.0) * 0.1 = 0.05s`
- Обычная атака: `(1.0 / 2.0) * 1.0 = 0.5s`

**Персонаж с attackSpeed = 0.5:**
- Первая атака: `(1.0 / 0.5) * 0.1 = 0.2s`
- Обычная атака: `(1.0 / 0.5) * 1.0 = 2.0s`

### 🔧 Настройка баланса

- **firstAttackTime = 0.1**: Первая атака в 10 раз быстрее обычной
- **firstAttackTime = 0.5**: Первая атака в 2 раза быстрее обычной
- **baseAttackTime = 1.0**: Стандартное время атаки
- **baseAttackTime = 0.8**: Все атаки на 20% быстрее
- **antiOrbWalkingCooldownMultiplier = 1.0**: Защита равна реальному времени атаки
- **antiOrbWalkingCooldownMultiplier = 0.8**: Защита на 20% меньше реального времени

### 🛡️ Anti-Orb Walking System

**Как работает защита:**
1. `antiOrbWalkingCooldown` теперь **динамически рассчитывается** как `realAttackTime * multiplier`
2. **Реальное время атаки** = `(1.0 / attackSpeed) * baseAttackTime`
3. **Защита от abuse** автоматически адаптируется к скорости атаки персонажа

**Примеры:**
- Персонаж с `attackSpeed = 1.0`: защита = `1.0s * 1.0 = 1.0s`
- Персонаж с `attackSpeed = 2.0`: защита = `0.5s * 1.0 = 0.5s`
- Персонаж с `attackSpeed = 0.5`: защита = `2.0s * 1.0 = 2.0s`

### 🔄 Fast Attack Reset System

**Как работает ресет быстрой атаки:**
1. **Быстрая атака доступна** если прошло `fastAttackResetTime` секунд с последней атаки
2. **После каждой атаки** таймер сбрасывается
3. **Периодический ресет** позволяет использовать быструю атаку многократно

**Примеры:**
- `fastAttackResetTime = 1.0s`: быстрая атака доступна после 1 секунды без атак
- `fastAttackResetTime = 1.5s`: быстрая атака доступна после 1.5 секунды без атак
- `fastAttackResetTime = 2.0s`: быстрая атака доступна после 2 секунд без атак

**Сценарии использования:**
1. **Начало боя**: Первая атака всегда быстрая
2. **Пауза в бою**: После 1 секунды без атак следующая атака будет быстрой
3. **Смена цели**: Если игрок переключается между целями с паузой, получает быструю атаку

## Общая совместимость

- Система полностью совместима с существующим кодом
- Не требует изменений в других скиллах
- Работает с существующей системой скорости атаки (CharacterStats.attackSpeed)
