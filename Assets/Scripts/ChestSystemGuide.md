# 🎁 Система сундуков в инвентаре

## 📋 Описание

Универсальная система сундуков, которая позволяет создавать предметы-сундуки в инвентаре. При двойном клике на сундук он открывается, выдает награды игроку и исчезает из инвентаря.

## ✨ Возможности

- **Фиксированные предметы**: Гарантированные награды с шансом 100%
- **Случайные предметы**: Предметы с настраиваемым шансом выпадения
- **Роллинг статов**: Предметы могут роллить статы как при дропе с монстров
- **Золотые награды**: Дополнительное золото с настраиваемым шансом
- **Динамические статы**: Поддержка предметов с динамическими статами
- **Уведомления**: Информация о полученных наградах

## 🛠️ Как создать сундук

### 1. Создание ChestItemData

```csharp
// Создайте ScriptableObject: Right-click → Create → Items → Chest Item
// Настройте:
- Chest Name: "Сундук новичка"
- Description: "Описание сундука"
- Gold Reward: 100
- Gold Chance: 1.0
```

### 2. Настройка наград

```csharp
// Добавьте награды в список rewards:
- Item ID: 5 (Blade of Enigma)
- Quantity: 1
- Drop Chance: 1.0
- Is Guaranteed: ✓ true

- Item ID: 6 (другой предмет)
- Quantity: 1
- Drop Chance: 0.8
- Is Guaranteed: ✗ false
- Roll Stats: ✓ true (если нужен роллинг статов)
- Level: 1 (уровень для роллинга)
```

### 3. Создание Item

```csharp
// Создайте Item: Right-click → Create → Inventory → Item
// Настройте:
- Item Type: Chest
- Item Name: "Сундук новичка"
- Can Use: ✓ true
- Can Drop: ✓ true
- Can Sell: ✓ true
- Max Stack: 1
- Chest Data: перетащите созданный ChestItemData
```

### 4. Добавление в ItemDatabase

```csharp
// Откройте ItemDatabase
// Добавьте предмет с уникальным ID
// Перетащите созданный Item в соответствующую ячейку
```

## 🎮 Использование

### Для игроков:
1. Получите сундук в инвентарь
2. Двойной клик на сундук
3. Получите награды
4. Сундук исчезает из инвентаря

### Для разработчиков:
```csharp
// Добавление сундука в инвентарь
PlayerCore player = FindObjectOfType<PlayerCore>();
Item chestItem = ItemDatabase.Instance.GetItem(chestId);
player.Inventory.AddItem(chestItem, 1);

// Открытие сундука программно
chestItem.Use(player);
```

## 🧪 Тестирование

Используйте компонент `ChestTester` для тестирования:

1. Добавьте `ChestTester` на любой GameObject
2. Настройте `Chest Item ID` (ID сундука в ItemDatabase)
3. Используйте кнопки в Inspector или Context Menu:
   - "Add Chest to Inventory" - добавить сундук в инвентарь
   - "Open Chest Directly" - открыть сундук напрямую
   - "Create Test Starter Chest" - создать тестовый сундук

## 🔧 Технические детали

- Сундуки используют существующую систему `Item.Use()`
- Поддерживается роллинг статов через `Item.GenerateDynamicItem()`
- Интеграция с `InventorySlot.OnPointerClick()` для двойного клика
- Уведомления через `Debug.Log()` (можно интегрировать с UI системой)

## 🚀 Расширения

Система легко расширяется для:
- Анимаций открытия сундука
- Звуковых эффектов
- UI уведомлений
- Специальных эффектов
- Условных наград (по уровню игрока, классу и т.д.)
