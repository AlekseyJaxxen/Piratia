# Универсальный генератор предметов

## Описание изменений

Генератор предметов переработан для использования универсальных диапазонов характеристик с ограничениями по типам предметов.

## Новые характеристики предметов

### Оружие
- **Минимальный урон** (min-max диапазон)
- **Максимальный урон** (min-max диапазон)
- **Основная характеристика** (сила, ловкость, дух, телосложение, точность)

### Броня
- **Защита** (плоская защита, вычитается из урона)
- **Физическое сопротивление** (процент снижения физического урона 0-100%)
- **Основная характеристика** (сила, ловкость, дух, телосложение, точность)

### Ботинки
- **Защита**
- **Уклонение**
- **Основная характеристика** (сила, ловкость, дух, телосложение, точность)
- **Скорость бега**

### Перчатки
- **Защита**
- **Шанс урона** (%)
- **Бонус к урону** (добавляет к минимальному и максимальному урону)
- **Основная характеристика** (сила, ловкость, дух, телосложение, точность)

### Шлем (Шапка)
- **Защита**
- **Шанс критического урона** (%)
- **Основная характеристика** (сила, ловкость, дух, телосложение, точность)

### Кольца
- **Только основная характеристика** (сила, ловкость, дух, телосложение, точность)

### Ожерелье
- **Скорость бега**

## Новые классы

Созданы следующие новые классы предметов:

- `GlovesItem.cs` - для перчаток
- `RingItem.cs` - для колец  
- `NecklaceItem.cs` - для ожерелий

## Обновленные компоненты

### ItemGenerator.cs
- Добавлены специфичные диапазоны для каждого типа предметов
- Улучшена логика генерации статов с учетом типа предмета
- Новые параметры конфигурации: `primaryStatChance`, `itemSpecificStatChance`

### Item.cs
- Добавлен новый стат `damageChanceBonus` (шанс урона)
- Добавлен диапазон `damageChanceRange`
- Обновлена система копирования свойств для поддержки новых статов

## Использование

1. Создайте новый ItemGenerator в проекте
2. Настройте LevelConfig для разных уровней с учетом новых диапазонов
3. Используйте функцию "Generate Sample Configuration" для быстрой настройки
4. Генерируйте предметы через меню "Generate Items" или программно

## Пример конфигурации

```csharp
level = 10,
weaponMinDamageRange = new Vector2Int(25, 35),
weaponMaxDamageRange = new Vector2Int(35, 45),
armorDefenseRange = new Vector2Int(5, 12),
armorPhysicalResistRange = new Vector2Int(1, 8),
bootsDodgeRange = new Vector2Int(4, 10),
glovesDamageChanceRange = new Vector2Int(4, 12),
helmetCritChanceRange = new Vector2Int(2, 8),
strengthRange = new Vector2Int(0, 3),
primaryStatChance = 0.7f,
itemSpecificStatChance = 0.8f
```
